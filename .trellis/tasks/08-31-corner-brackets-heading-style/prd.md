# 新增双角括号标题样式

## Goal

在“自定义主题 → 可视化设计 → 标题 → 样式预设”中新增“双角括号”样式，仅保留参考图中的右上与左下两个折角。

## Requirements

- 在现有 `headingStylePresets` 中增加 `corner-brackets` 预设，按钮名称为“双角括号”，可供 H1–H4 使用。
- 标题内容保持紧凑的行内宽度，并留出少量内边距。
- 使用标题 `.content::before` 绘制左下折角，使用 `.content::after` 绘制右上折角。
- 折角使用现有 `--wemd-primary-color`，正文颜色仍由标题颜色设置控制。
- 不包含参考图右侧的点状装饰，不新增自动编号、设计变量、组件或依赖。
- 扩展现有标题预设测试，覆盖预设注册以及两个折角的关键 CSS。

## Acceptance Criteria

- [x] 可视化标题样式预设网格显示“双角括号”。
- [x] 选择后标题仅出现左下、右上两个主题色折角。
- [x] 标题保持内容宽度，长标题不超过容器宽度。
- [x] 既有标题预设测试继续通过，新预设有回归断言。
- [x] 原有预设 ID 与行为不变。

## Notes

- 这是轻量任务，直接复用现有标题预设生成器，PRD 足以覆盖范围。
