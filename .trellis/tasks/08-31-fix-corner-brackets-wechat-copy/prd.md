# 修复双角括号微信复制丢失

## Goal

修复“双角括号”标题样式在复制并粘贴到微信公众号编辑器后消失的问题。

## Requirements

- 保留用户已将折角边框从 `1px` 调整为 `3px` 的本地微调。
- 两个伪元素使用不可见 NBSP 作为存活锚点，避免 Juice 生成的装饰节点因内容为空而被微信公众号清洗删除。
- 将存活锚点设置为零字号、零行高，不改变预览中的折角尺寸或标题排版。
- 在微信复制集成测试中覆盖完整的 `generateCSS → processHtml` 链路，确认生成两个非空装饰节点，并保留四条内联边框及已解析的实际颜色值。
- 新建并维护微信公众号复制避坑文档，只记录本次及既有兼容问题的症状和正确写法，并加入前端规范索引。
- 不修改共享复制协议、其它标题预设或主题数据结构。

## Acceptance Criteria

- [x] 双角括号复制 HTML 中包含两个不可见 NBSP 装饰节点。
- [x] 两个节点分别保留左下和右上折角的内联边框样式及实际颜色值。
- [x] 装饰节点不再为空，模拟公众号空节点清洗后折角仍存在。
- [x] 双角括号预设测试与微信复制集成测试通过。
- [x] TypeScript 检查通过，任务文件定向 lint 无错误。
- [x] 微信复制避坑文档已建立并加入前端规范索引。

## Notes

- 根因：`content: ""` 被 Juice 内联为两个空 `<span>`，微信公众号会删除空节点；边框简写中的 CSS 颜色变量也无法在复制解析阶段可靠展开。
- 全仓 lint 仍被既有 `apps/server/src/proxy/proxy.controller.spec.ts` 的 3 个错误阻断；本任务三个 Web 文件定向 lint 通过。
- 这是轻量修复，PRD 足以覆盖实现范围。
