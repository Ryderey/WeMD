# PRD：加粗配色独立于主题色

来源方案：`docs/plans/2026-09-28-independent-bold-color.md`（本次设计依据，已复制为 `design.md`）。

## 背景

自定义可视化主题里，加粗的装饰色（荧光笔背景、底部涂抹、下划线）直接引用 `--wemd-primary-*`，只有文字色能被 `strongColor` 覆盖。用户希望「底部涂抹」等加粗效果使用与主题色无关的独立配色：改主题色、改渐变主题色都不应影响加粗颜色。

`strongColor: "inherit"` 是自动取色分支的哨兵值，不是严格意义上的继承正文色，因此不能直接把 `strongColor` 提升为「文字＋装饰」公共色——旧主题可能已配置「黑色文字 ＋ 主题色涂抹」，那样会破坏它。

## 需求

1. 新增可选字段 `strongAccentColor`，表示独立加粗配色（纯色）。缺失 / `undefined` / 空字符串 = 跟随主题；合法纯色 = 自定义；非法类型或无效颜色 = 安全回退为跟随主题。
2. 独立配色同时控制加粗的默认文字色与装饰色，覆盖全部六种加粗样式（`none` / `color` / `highlighter` / `highlighter-bottom` / `underline` / `dot`），不能只改文字色。
3. `strongColor` 保持原语义：仅作为文字覆盖色，优先级高于独立配色；装饰色始终使用独立配色。
4. 配置独立配色后，修改 `primaryColor` 或 `primaryGradient` 不得改变加粗的实际取色。
5. 切换加粗样式不得清空独立配色。
6. 未配置新字段的旧主题，取色行为与现状逐条一致（含彩色加粗的渐变分支、荧光笔的渐变分支、着重号随文字取色）。
7. 兼容性回退必须实现在 CSS 生成路径内（`generators/variables.ts`、`generators/global.ts`），因为 `themeStore` 加载与导入时会绕过 `ThemePanel` 的默认值合并直接调用 `generateCSS`。
8. 保存、应用、复制主题、关闭重开、JSON 导入导出、CSS 导出全链路保留该字段效果；无效新字段不得导致整批自定义主题加载失败。
9. 界面在「全局」标签页的加粗样式之后提供「加粗配色」的「跟随主题 / 自定义」模式切换与色板，并把「其他」标签页已有的加粗文字颜色控件移动到此处的「加粗文字颜色」，不保留重复入口。
10. 「随主题色」样式按钮文案改为「彩色加粗」，内部 ID 仍为 `color`。`strongColor` 的 `inherit` 选项显示为「自动」，存储值不变。
11. 模式切换使用独立按钮（或已有开关），不得伪装成普通色块——现有 `ColorSelector` 按展示颜色去重，会把语义不同但颜色相同的两个选项合并。
12. 模式与颜色控件具备可访问名称与正确选中状态，支持键盘操作。
13. 独立配色生效时，彩色加粗不得继续使用主题渐变（避免 `color: transparent` 与旧渐变残留）。
14. 下划线在独立模式下拆为 `border-bottom-width` / `border-bottom-style` / `border-bottom-color` 长写属性，线宽与间距不变。

## 范围外

独立加粗渐变编辑器、每种加粗样式各存一套颜色、新的颜色处理依赖或通用配色状态框架、全局主题架构重构、数据库迁移、已有主题批量重写、`ThemePanel` / `themeStore` 的预先重构。

## 验收标准

### 主要场景（主题色紫、独立配色橙、样式=底部涂抹）

- [ ] 未覆盖文字色 → 橙字 ＋ 半透明橙涂抹。
- [ ] 文字色设为黑 → 黑字 ＋ 橙涂抹。
- [ ] 主题色改绿 → 加粗颜色不变。
- [ ] 改主题渐变 → 加粗颜色不变。
- [ ] 切换其他加粗样式 → 独立配色仍在。
- [ ] 切回「跟随主题」→ 恢复主题联动。
- [ ] 基础加粗仍遵守继承 / 显式覆盖规则。
- [ ] 标题、链接、引用、列表标记、代码等取色不变。

### 回归与持久化

- [ ] 六种样式 × 独立/跟随两种模式均验证。
- [ ] 旧主题在有、无显式 `strongColor` 两种情况下效果不变。
- [ ] 主题渐变有、无两种情况均验证。
- [ ] 保存、应用、重开、刷新、复制主题均保留配置。
- [ ] JSON 往返与 CSS 导出正确。
- [ ] 新字段缺失、空值、非法类型、非法颜色均安全回退。

### 自动化

- [ ] 变量与生成器测试覆盖独立色、12%/18% 透明、六样式、覆盖色优先级、旧配置回退。
- [ ] 独立性断言：生成 CSS 后改 `primaryColor` / `primaryGradient`，加粗有效颜色不变。
- [ ] 组件测试覆盖模式切换、选色、改主题色、切样式后的状态与输出。
- [ ] 微信复制测试覆盖底部涂抹与下划线：走完现有复制流程后内联颜色为实际值，无未解析的相关 CSS 变量。
- [ ] `pnpm --filter @wemd/web run test -- --run`、`lint`、`build` 通过；基线失败需区分标注，不得把未通过写成通过。

### 人工验收

- [ ] 浏览器预览检查正文加粗、长文本换行、列表与引用内加粗、加粗嵌套链接，无异常透明文字或装饰残留。
- [ ] 微信编辑器粘贴（底部涂抹 / 荧光笔 / 下划线）验证粘贴后与保存重开后的颜色；无法执行时在交接中明确标注未验证。
