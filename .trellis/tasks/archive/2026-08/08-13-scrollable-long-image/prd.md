# 产品化滚动长图并验证公众号兼容性

## Goal

让作者显式上传一张长图，并在 WeMD 预览和微信公众号文章中以固定高度、内部纵向滚动的区域展示。

## Requirements

- 新增 `scroll-image` Markdown 块语法，默认高度 320px，允许 160–800px。
- 内容只接受一张标准 Markdown 图片；非法内容不得生成滚动组件。
- 组件必须提供读者可见的上下滑动提示和键盘可聚焦的滚动区域。
- 桌面工具栏提供独立入口；普通上传、粘贴图片和横向图片流保持不变。
- 专用入口先选择文件、再设置高度并预览，确认后才上传；支持失败重试。
- 复用现有图床和 2MB 自动压缩，不增加依赖或后端接口。
- 公众号复制后必须保留固定高度、纵向滚动、图片自适应和提示文案。

## Acceptance Criteria

- [x] `::: scroll-image [height]` 可稳定渲染单张滚动长图。
- [x] 省略高度时为 320px，越界整数夹到 160/800，非数字块不转换。
- [x] 设置弹窗提供 240/320/420px 预设和 160–800px 自定义值。
- [x] 取消不会上传，失败可原地重试，成功后插入完整语法并释放本地预览 URL。
- [x] Core、Web、复制集成测试、lint 和构建通过。
- [x] Chrome DevTools MCP 验证 WeMD 本地滚动，以及公众号粘贴、界面显示和保存重开。
- [x] 测试草稿和临时图片在取证后删除，不发表文章。

## Constraints

- 基线为 `bugfix@247bf56`，实现分支为 `codex/scrollable-long-image`。
- 关键公众号兼容样式由组件内联，不批量修改内置主题。
- 公众号真实验收止于编辑器粘贴后的界面与 DOM/样式检查，不发送预览。
