# 导出图文：交付界面

## Goal

把 AI 改写和首图渲染整合成可预览、编辑、复制和打包的发布流程。

## Requirements

- 三类导航入口使用同一个懒加载对话框，不复制业务状态。
- 对话框包含 AI 配置、提示词编辑/导入、生成状态、首图设置与预览、正文编辑和结果操作。
- 复制文本和 `article.txt` 固定为 `标题：{原始标题}\n\n{正文}`。
- ZIP 使用现有安全标题和时间戳命名，只包含 `cover.png` 与 UTF-8 `article.txt`。
- 关闭或导出均不得写回编辑器。

## Acceptance Criteria

- [x] Header、浮动工具栏和移动端更多菜单均可打开对话框。
- [x] 空文章、缺少配置、生成中、生成失败和生成成功状态清晰且操作不可重复触发。
- [x] 文案可编辑，重新改写可替换结果，复制后有成功反馈。
- [x] 改封面专用标题不会改变复制/导出的正文标题。
- [x] ZIP 内容、编码、文件名和 PNG 尺寸均有自动化测试。

## Out of Scope

- 保存历史版本、写回 Markdown、分享链接、发布到第三方平台。
