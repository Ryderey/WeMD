# 新增红底编号标题样式

## Goal

在“新建/编辑自定义主题 → 可视化设计 → 标题 → 样式预设”按钮网格中新增截图所示的红底白字编号标签样式。

## Requirements

- 在现有 `headingStylePresets` 中增加一个可供 H1–H4 选择的预设，名称为“编号标签”；该按钮与“左侧竖线”“背景块”等现有预设并列显示。
- 预设将标题 `.content` 渲染为紧凑的行内标签：主题色实底、白色加粗文字、小圆角，以及右下方同色系硬阴影，整体接近截图的红色编号标题。
- 标题文字（如“8. 表格”）仍由 Markdown 内容提供；该预设不新增或自动生成编号。
- 继续使用 `--wemd-primary-gradient` 作为标签底色，因此用户可通过现有主题色/渐变设置调整颜色；不新增变量、控件或依赖。
- 在现有标题预设单元测试中覆盖预设登记与关键 CSS 输出。

## Acceptance Criteria

- [x] 标题设计器中可选择“编号标签”。
- [x] 选中预设后，H1–H4 的 `.content` CSS 含有行内标签、白字、主题色背景、2px 圆角和偏移硬阴影。
- [x] 既有标题预设测试继续通过，新预设有回归断言。
- [x] 原有标题预设的 ID 和渲染行为不变。

## Notes

- 这是轻量任务：只扩展已有预设注册表、生成器和测试，PRD 足以覆盖实现范围。
