# 导出图文：首图模板

## Goal

将解析出的文章标题稳定渲染为跨平台一致的 1080×1440 首图。

## Requirements

- 标题来源为第一个真实 H1、文件名、`未命名文章`，按此顺序回退。
- 提供暖白黄黑和冷白蓝青两套参考模板。
- 暖白使用内置 Noto Sans SC Bold；冷白使用内置 LXGW WenKai Lite；随包附 OFL。
- AI 建议的高亮词可编辑或清空，必须是当前封面标题的原文片段。
- 用户可临时改短封面标题，不影响文案标题与原 Markdown。
- 自动换行和缩放必须保留完整标题；最小字号仍溢出时阻止导出。

## Acceptance Criteria

- [x] H1 解析忽略代码围栏内的 `#`，不把 H2 或正文首行当标题。
- [x] Windows 与 Unix 文件路径均正确去掉目录和扩展名。
- [x] 两套模板生成 1080×1440 PNG，字体加载完成后才截图。
- [x] 重复、无效和超过两个的高亮词被规范化。
- [x] 普通长标题自动适配；极端长标题给出要求缩短的明确状态。

## Out of Scope

- 自由拖拽排版、上传背景、更多模板和 AI 生成图片。
