# 导出图文

## Goal

让用户从当前 Markdown 一次获得可审校的图文短文案和统一首图，并可复制文案或导出 ZIP，同时不修改原文。

## Requirements

- 桌面顶部栏、隐藏标题栏浮动工具栏和移动端更多菜单均提供“导出图文”入口。
- 文章标题优先取第一个真实 H1；没有 H1 时取文件名；再回退“未命名文章”。
- OpenAI Chat Completions 兼容 AI 将文章改写为 350–500 字短文案，并建议最多两个标题高亮词。
- AI 配置区在 API Key 同行提供连通性探测，验证当前端点、模型与授权但不改写文章。
- Electron 窗口最大化或还原后，顶部菜单在最小窗口宽度内不得横向溢出或遮挡窗口控制按钮。
- Web API Key 仅驻留内存；Electron API Key 使用 safeStorage 加密持久化且不回传明文。
- 首图为 1080×1440 PNG，内置暖白粗黑和冷白文楷两套模板，字体随应用打包。
- 结果可编辑、重新改写、复制，并导出包含 `cover.png` 与 UTF-8 `article.txt` 的 ZIP。
- 原 Markdown、编辑器标题与文件内容不得被该流程改写。

## Acceptance Criteria

- [ ] Web 与 Electron 均能完成配置、改写、预览、复制和导出。
- [ ] 两个示例的改写结果遵循已审定提示词：事实准确、去除 Markdown/图片/链接噪音、保留限制与风险。
- [ ] 同一标题在 Web、Windows 与 macOS 使用内置字体生成一致布局。
- [x] 无 H1、超长标题、非法 AI 响应、网络/CORS 错误和安全存储不可用都有明确反馈。
- [x] ZIP 只含 `cover.png` 与 `article.txt`，文案标题使用原始解析标题。
- [x] 三个子任务按 AI → 首图 → 交付顺序完成并通过各自验证。

## Out of Scope

- 多提示词模板库、自由首图设计器、AI 生成背景图、服务端 AI 代理、写回编辑器。
