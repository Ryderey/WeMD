# 五款阅读模板显式 HTML 标题预设

## 用户已确认

- 使用调研方案 A：作者显式写 HTML，选择标题样式时显示提示并可复制结构。
- 新建分支修改：`codex/reading-heading-html`，从 `bugfix` 创建。
- 创建 Trellis 任务后继续实施；不需要重新询问方案或实施许可。

## 需求

- 为素笺、墨刊、青岚、蓝图、朱砂提供对应的标题预设。
- 保留现有主标题设置；支持编号字号、颜色、间距与同排编号栏宽的可视化编辑。
- 选择预设后显示当前标题级别的 Markdown 用法、作者手填编号的说明和 HTML 结构复制按钮。
- HTML 示例包含编号、主文字和章前线，作者自行粘贴到 Markdown 标题中；不再要求为该结构另外写 `---`。提示避免重复线。
- 五款模板默认配置对应的 H2 样式；示例预览应能直接看到显式结构。
- 复制成功、失败均有反馈，浏览器和 Electron 使用现有剪贴板通道。

## 验收

- 五款选项均可选择、显示对应提示、复制准确 HTML；复制内容不含 `##`，提示示例包含当前级别的 `#`。
- 素笺居中双行、青岚双行及编号短线、另外三款同排悬挂；主标题和数字互不覆盖。
- 普通 Markdown 标题不会自动生成数字，未标记的标题不出现空编号栏或章前线。
- 主预览、设计器预览、最终微信复制输出中结构与参数一致；标题内强调和链接保留。
- 原 55 份 CSS 基线及章节标签行为不变；新增五份预设基线。
- 保存、刷新、JSON 导入导出保留新设置，非法导入值安全回退。
- 不修改 parser，不新增依赖，不改其他排版与无关 server 工作树变更。
- 最终报告区分自动验证、浏览器验证和未完成的微信实机粘贴。
