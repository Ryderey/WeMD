# 修正章节标签标题与 WeDraft 参考图的视觉差异

## Goal

使 WeMD「章节标签」预设在用户选择后，默认标题视觉与所附 WeDraft「小哈公社New」红框参考一致；验收不能止于节点存在或样式已内联。

## Requirements

- 用户确认最新附图是预期参考，当前 WeMD 没有对齐。
- 目标：上方 SECTION 01 小字，下方中文主标题；珊瑚红标签和 3px 左竖线、橙色主标题，13px 左内距。
- 主标题采用 20px、1.5 行高、750 字重、0.2px 字距；标签采用 10px、1.4 行高、700 字重、1.6px 字距、4px 下间距。
- 默认主标题颜色 #FFA900；标签和竖线颜色 #F96E57。选择该预设后，标题的字号、颜色、行高、字距等仍可通过现有控件微调。
- 用户接受显式 `## <span class="chapter-label">SECTION 01</span>建立阅读层级` 写法；选择预设时展示示例、手动编号说明及“复制标签代码”按钮。按钮只复制 `<span class="chapter-label">SECTION 01</span>`，成功与失败均给出反馈。
- 标签随作者正文保留。分隔线继续由作者显式写 ---。不移植整套小哈主题，不改变 parser，不调整全局默认主题颜色。
- 不隐式迁移旧自定义主题；旧的章节标签主题可通过重新选择预设载入新的参考参数。
- 保留与本任务无关的 server 工作区改动和已有未追踪文档。

## Acceptance Criteria

- [x] 在 dev:web 主界面，按显式 span 示例输入正文，选择、保存并应用 H2 章节预设后出现 SECTION 01 与主标题两行；输入示例和行为边界在设计器中可见。
- [x] “复制标签代码”产生完全一致的纯文本 span，可通过真实编辑器粘贴使用；浏览器和 Electron 成功、复制失败的反馈有回归验证。
- [x] 通过真实复制渲染入口自动验证载荷保留作者标签、主标题格式和两种内联颜色；浏览器点击公众号复制成功，但工具未能读取原生富文本剪贴板，此限制与普通未标注标题的单行行为如实记录。
- [x] 带显式标签的真实 parser 与复制处理产物的字号、双配色、行高、字重、字距、边框和间距符合参考。
- [x] 515px 视口、同一字体环境下，与从 WeDraft 源码抽取的参考标题对照，高度为 48px，标签与主标题保持两行。
- [x] 长标题和窄正文宽度正确换行；复制 HTML 不残留 var(--wemd-\*)，两个颜色仍分别内联。
- [x] 设计器、文章预览、最终复制 HTML 使用一致的标题参数；后续微调控件有效。
- [x] 其他预设与 54 个非章节标签旧基线逐字不变；仅章节标签基线的明确差异获审阅后更新。
- [x] 微信实际粘贴与截图字体差异独立记录，不以自动化内联检查冒充人工验收。
