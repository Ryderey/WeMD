# 暖白引语闭引号位置修复：验证记录

日期：2026-09-20。任务：`09-21-fix-warm-quote-close-position`。

## 方法

1. **单测**（`richPostCover.test.ts`）：mock `Range#getBoundingClientRect` 与画布矩形，钉住"最后一个字的右下 + 固定 em 偏移"的公式，以及预览 0.25 缩放下的坐标换算；另钉住无布局环境（jsdom 零矩形）时保留兜底坐标。
2. **浏览器实测**（Chrome，dev server `http://localhost:5173`）：在页面内动态 `import('/src/services/richPostCover.ts')` 调用真实的 `captureRichPostCover` 生成 1080×1440 PNG（走完整导出路径：字体加载 → 字号收缩 → 引号定位 → `domToBlob`），再对导出像素做统计（强调色 `#f7bf00` 的像素 = 引号，`<80` 的深色像素 = 文字）。
