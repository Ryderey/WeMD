# 修复底部下划线双行标题遮挡

## Goal

修复“自定义主题 → 可视化设计 → 标题样式 → 底部下划线”在标题换成两行时，上一行下划线遮盖下一行文字的问题。

## Requirements

- 每一行标题仍保留独立的底部下划线。
- 下划线与下一行文字之间必须留出足够间距，不得遮挡字形。
- 单行标题的下划线样式保持不变。
- 不影响其他标题样式预设，也不引入新依赖。

## Acceptance Criteria

- [x] 两行及以上的“底部下划线”标题中，下划线不再覆盖下一行文字。
- [x] “底部下划线”仍按每行文字分别绘制，不退化为整个标题仅一条线。
- [x] 现有标题样式预设测试通过，并新增针对行间距的回归断言。

## Notes

- 用户提供的截图显示，固定下划线偏移在紧凑标题行高下会进入下一行字形区域；多行标题应使用浏览器默认下划线位置。
- 核心修改文件：`apps/web/src/components/Theme/ThemeDesigner/generators/presets.ts`。
