# 在主题设计器增加文章底色

## Goal

在可视化主题设计器的“全局”区域增加文章底色设置，让用户通过少量快捷色块设置整篇文章的纯色背景。

## Requirements

- 在 `DesignerVariables` 中增加文章底色变量，并为旧的可视化主题提供透明回退。
- 在主题设计器“全局”区域显示“文章底色”设置。
- 第一版只提供透明、浅绿、暖白、淡蓝四个快捷色块；点击后立即更新主题预览。
- 生成的主题 CSS 将非透明底色应用到根容器 `#wemd`，透明选项恢复原有无底色行为。
- 沿用现有主题保存、导入导出和微信复制规范化链路，不新增文章 frontmatter、依赖或背景图片能力。
- 保持手写 CSS 主题与内置主题现有行为不变。

## Acceptance Criteria

- [x] 全局设计区可见文章底色设置和四个有明确名称的快捷色块。
- [x] 选择快捷色块会更新 `DesignerVariables`，并在主题预览中生效。
- [x] 透明底色不产生可见背景，三个彩色预设生成正确的 `#wemd` 背景色。
- [x] 缺少新字段的旧可视化主题仍能加载、预览和保存。
- [x] 微信复制继续将整篇纯色背景下沉到正文块，不覆盖局部显式背景。
- [x] 微信复制后由连续内层承接段落间距，正文不会呈现逐行白色间隔。
- [x] 相关单元测试、类型检查和 lint 通过。

## Notes

- 首期把文章底色定义为主题属性，不作为 Markdown 内容插入，也不作为单篇文章独立覆盖字段。
- 快捷色块的具体色值应采用低饱和浅色，并集中定义，避免 UI 与测试重复硬编码。
- 背景图片、渐变、任意颜色选择器和局部背景块均不在本期范围内。
- 技术评估保留在 `research/implementation-difficulty.md`。
