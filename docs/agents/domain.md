# Domain docs

## Layout

Single-context.

- `CONTEXT.md` at the repo root describes the project's domain language and concepts.
- `docs/adr/` at the repo root contains architectural decision records.

## Consumer rules

- Read `CONTEXT.md` before suggesting architectural changes or bug fixes.
- Read relevant `docs/adr/*.md` before proposing changes that might reverse or extend past decisions.
- When adding new domain terms or changing existing ones, update `CONTEXT.md`.
